# form_nav 项目背景与框架说明

## 项目概况

- 路径：`~/catkin_ws/src/form_nav`，ROS Noetic + PX4 + Gazebo，多无人机编队导航；目标是在仿真验证后实机实验并写论文。
- 技术栈：全局层 A*（纯 A*，含轻量取锯齿后处理；kinoA* 代码保留但当前未启用），局部层 MPC（CasADi + IPOPT），静态避障用 KD-tree 查询每个预测步最近的 3 个障碍点构造 softplus 势垒，编队通信拓扑为有向无环图（无双向通信），各机互发预测轨迹用于编队防碰。

## 框架（当前）

### 全局层（分布式）

- 每架无人机用自己的起点状态和编队分配的目标点独立调用 A* 规划自己的全局轨迹；编队偏移只用于分配终点，以及作为规划/控制的软约束。
- 全局轨迹的作用：提供全局方向、避免局部最优，不再作为带时间戳的逐点参考。
- launch 中 `global_planner:=astar/kino_astar` 可切换全局规划器，当前默认 A*。

### 局部层（MPC 滚动子目标）

- 在全局轨迹上按累积弧长投影当前点得到 `s0`，沿路径前推 `lookahead_distance`（默认 1.0 m）选取滚动子目标；MPC 只跟踪该子目标（终端惩罚），速度字段不使用。
- 预测时域 `N=10, dt=0.05 s`（0.5 s 视界），整个视界跟踪同一个子目标。
- 上一轮解热启动、Opti 复用、最近障碍点重查询重规划循环、终点悬停锁定。
- yaw 参考 = 当前点指向滚动子目标的水平方向角（`atan2(goal−cur)`），复用终端子目标惩罚的 yaw 通道（独立权重 `w_yaw`，不新增代价项）；参考在路径折角处相对当前 yaw 做 ±π 连续化，与子目标过近时保持上一周期参考；进入终点范围（距全局终点 < `yaw_lock_dist`，默认 0.3 m）后冻结参考、保持机头方向，避免悬停漂移导致的冗余转头。

### 运动学模型（2026-08-30 更新：yaw 与线速度解耦 + 精确离散化）

- 状态 `X = [x, y, z, ψ, vx, vy, vz, ω]`，控制 `U = [vx_c, vy_c, vz_c, ω_c]`（**惯性系**线速度指令 + yaw rate 指令）。
- 连续模型：
  - `ṗ = v_e`
  - `v̇_e = (K_v v_c − v_e) / τ_v`
  - `ψ̇ = ω`
  - `ω̇ = (K_ω ω_c − ω) / τ_ω`
- 一阶系统按零阶保持解析解**精确离散化**：`X_{k+1} = A X_k + B U_k`（常数矩阵，非 Euler 近似）。
- 参数：`τ_v=0.7 s`（launch 当前值，代码默认 0.8）、`τ_w=0.5 s`、`K_v=K_w=1`（`K_w=1` 修正了旧模型 `π/180` 导致的"57 倍 yaw 模型失配"问题）；`u_max=2.0 m/s`（线速度指令上限）、`w_max=2.0 rad/s`（yaw rate 指令上限）。
- 线速度与 yaw 完全解耦：急转弯时线速度不再被 yaw 拖累，yaw 可独立快速转动。
- 制动约束（2026-09-04 起为显式匀减速刹停）：
  `||v||² ≤ 2·a_brake·d_g`（`a_brake` 为常数减速度上限，launch 默认 1.2 m/s²，
  建议 1.0~1.5；`d_g` 为到全局终点的直线距离），实现时平方化为
  `||v||⁴ ≤ (2·a_brake)²·d_g²` 避免开方/除零处的雅可比 NaN。替代旧的
  `τ_v·||v|| ≤ d_g` 精确停车约束——旧式对应"速度指令置零后一阶指数衰减"，
  低速段渐近趋零、所需距离随速度线性偏大，终点锁定（`d<0.1 且 v<0.1`）前
  易触发"推—刹—推"极限环；新式以制动能力为界，终点附近允许保留较高速度，
  由终端代价与到达锁定决定最终刹停。

### 编队与避碰

- 优先级避让：利用 DAG 拓扑"接收者避让发布者的预测轨迹"，天然形成一致优先级（leader 最高，逐级向下），避免对称避让振荡。
- 队形：巡航段松散，只要求终点恢复编队。
- 障碍避碰：KD-tree 查询每个预测步最近的 3 个障碍点（障碍点作为参数参与优化，代价可导）；
  softplus 势垒（2026-09-03 起与 compare/safe-softpus 分支一致）
  `H_oa = Σ (Wo/d_scale)·softplus(k_oa·(D̄−d_eff))`，其中
  `d_eff = ||p−o|| − r_drone`（扣无人机半径），`D̄=detect_range_` 为势垒中心距离，
  `d_scale = max(d_eff − safe_dist, 0.01)`（`safe_dist` 为有效距离下限 L，
  launch 默认 0.1 m，距离下限处截断为 0.01 使近距惩罚快速抬升）；处处可导、
  无硬边界、靠近障碍时惩罚增大且梯度有界，替代旧的死区对数势垒；
  另设近距兜底悬停（`hold_dist`）。
- 机间避碰（2026-09-03 起与静态避障同形式）：邻居预测轨迹按求解时间网格对齐后
  作为参数参与优化；`d_eff = ||p_i−p_j|| − 2·r_drone`（有效间距），
  `H_ca = Σ (Wc/d_scale)·softplus(k_ca·(d_act_ca−d_eff))`，
  `d_scale = max(d_eff − d_safe_ca, 0.01)`；launch 默认 `w_ca=20`、
  `d_safe_ca=0.2 m`、`d_act_ca=1.0 m`、`k_ca=1.0`。
- 动态障碍避碰（2026-08-31 更新：点-折线最短距离；2026-09-02 更新：softplus
  势垒）：动态障碍物（圆柱/球体）轨迹已知（仿真阶段由 `random_obs` 按解析轨迹
  发布 ground truth），MPC 单独维护动态障碍物表，按求解时间网格对齐后作为参数
  加入形状感知势垒。距离口径不再是"预测步 k 位置 ↔ 障碍物第 k 步位置"的点对点
  对齐，而是每个预测步对障碍物轨迹"0.5 s 窗口、0.1 s 节点"采样的折线（6 个节点、
  5 条线段）取最短距离：先沿线段投影 clamp 得最近点 c，再算"无人机中心到 c 处
  障碍物表面"距离 `d_surface`（球体任意方向扣半径；圆柱按高度带/顶底面/边缘圆环
  分段精确到表面），扣无人机半径得有效距离 `d_eff`，套 softplus 势垒
  `H_dyn = M_dyn·ln(1 + e^{k_dyn·(d_bar_dyn − d_eff)})`
  （参数 `m_dyn=50`、`d_bar_dyn=1.5 m`、`k_dyn=10`；`d_eff=d_bar_dyn` 时代价为
  `M_dyn·ln2`，越近越大但保持有限、无硬边界）。旧的"死区对数势垒"只在
  `d_eff < D̄` 内激活且边界附近梯度剧变，动态障碍物快速逼近时容易求解失败/悬停；
  softplus 无死区、处处光滑、惩罚持续存在，能持续引导无人机提前规避。
  这样即使求解滞后/卡顿导致时间步错开，也会避开障碍物该段扫掠路径，不再误判
  障碍物位置。动态点云只发 `/map_generator/dynamic_cloud` 用于可视化，**不进入**
  A*/静态 KD-tree，避免被当作静态障碍物污染全局规划。

### 消息约定

- `GlobalTrajectory`：每点 `[x, y, z, vx, vy, vz]`，世界系。
- `PredictedTrajectory`：每步 `[x, y, z, yaw, vx, vy, vz, yaw_rate]`，位姿与速度均按 `header.frame_id`（world）系——与新模型一致，节点不再做 body/world 转换。
- `DynamicObstacleTrajectory`：`[obstacle_id, shape, radius, height, dt, steps]` +
  每步 `[x, y, z, yaw, vx, vy, vz, yaw_rate]`（world 系）；`z` 为形状中心高度
  （圆柱 z=H/2 贴地、球体为球心），`shape`：0=球体、1=圆柱。

## 框架变更沿革（为什么）

- 原框架：全局层集中式"虚拟中心"轨迹 + 局部 MPC 逐点带时间戳跟踪，参考自 formation tracking-containment 论文。
- 修改为：分布式全局规划 + 滚动子目标路径跟随。原因：逐点跟踪对 kinoA* 路径质量过度敏感（节点处加速度跳变、绕障易振荡）；偏移后的集中式轨迹对跟随者可能穿障碍/速度不匹配；导航任务本质是"到达静态目标"、时间自由；全程刚性编队应用价值低。
- 2026-08-30：运动学模型由 `R(ψ)v_b` 耦合改为惯性系独立速度 + 精确离散化（见上）。
- 2026-09-02：动态障碍避碰惩罚由"死区对数势垒
  `W_dyn·max(0, −ln((d−L_dyn)/(D̄_dyn−L_dyn)))`"改为 softplus 形式
  `M_dyn·ln(1+e^{k_dyn(d_bar_dyn−d_eff)})`（默认 M=50、d_bar=1.5 m、k=10；
  键名 `w_dyn`/`d_safe_dyn`/`d_act_dyn` → `m_dyn`/`d_bar_dyn`/`k_dyn`）。
  原因：旧形式只在 `d_eff<D̄` 内激活、边界附近梯度剧变，动态障碍物快速逼近时
  易导致求解失败/悬停；softplus 无死区且处处光滑，代价随距离连续增大、梯度
  有界，引导无人机提前规避。
- 2026-09-03：静态障碍避碰惩罚由对数势垒
  `Wo·log(1 + (q_oa−L)/(d_c−L))` 改为与 compare/safe-softpus 分支相同的
  softplus 形式 `(Wo/d_scale)·softplus(k_oa·(D̄−d_eff))`，参数键名
  `q_oa` → `detect_range`（D̄，launch 默认 0.8 m）+ `k_oa`（陡度，默认 1.0）；
  `safe_dist`（有效距离下限 L）参数化 `d_scale = max(d_eff − L, 0.01)`，
  解决距离下限处截断代价不够大的问题。原因同动态障碍物：旧对数势垒在安全距离
  附近导数极大，狭窄走廊易导致求解失败/振荡；softplus 处处光滑、梯度有界。
- 2026-09-03：编队内机间距离惩罚由对数势垒
  `Wc·log(1 + (q_ca−L)/(d_c−L))` 改为与静态避障相同的 softplus 形式
  `(Wc/d_scale)·softplus(k_ca·(d_act_ca−d_eff))`（`d_eff=||p_i−p_j||−2r_drone`，
  `d_scale = max(d_eff − d_safe_ca, 0.01)`）；参数键名 `q_ca` → `d_act_ca`
  （D̄，launch 默认 1.0 m）+ 新增 `k_ca`（陡度，默认 1.0）。原因同静态避障：
  对数势垒在安全下限附近梯度剧变，机间接近时易导致求解失败/振荡；softplus
  处处光滑、近距惩罚抬升且梯度有界。
- 2026-09-04：制动约束由"速度指令置零等衰减"的精确停车约束
  `τ_v·||v|| ≤ d_g` 改为显式匀减速刹停 `||v||² ≤ 2·a_brake·d_g`
  （新参数 `mpc/a_brake`，默认 1.2 m/s²，建议 1.0~1.5；实现时平方化为
  `||v||⁴ ≤ (2·a_brake)²·d_g²` 保持处处光滑）。原因：旧约束把一阶速度响应
  滞后（τ_v≈0.7~0.8 s）当成唯一的刹车来源，低速段所需距离
  `τ_v·||v||` 线性偏大，与到达锁定条件（`d<0.1 且 v<0.1`）难以同时满足，
  终点前频繁触发 `current speed exceeds braking feasibility` 悬停并形成
  "推—刹—推"极限环；新约束以恒定减速度上限为界，低速段更宽松、允许
  终点附近保留较高速度，由终端代价与到达锁定决定最终刹停。节点制动预检
  同步改为 `v² > 2·a_brake·d_g` 时悬停。

## MPC 代价惩罚项（当前）

- 障碍物距离惩罚（softplus 势垒，`w_oa`/`k_oa`/`detect_range`/`safe_dist`）
- 动态障碍物距离惩罚（已知轨迹 + 点-折线最短距离 + 形状感知 softplus 势垒，
  `m_dyn`/`d_bar_dyn`/`k_dyn`）
- 编队内机间距离惩罚（softplus 势垒，`w_ca`/`d_act_ca`/`k_ca`/`d_safe_ca`）
- 控制输入惩罚（速度指令，`w_u`）
- 控制增量惩罚（`w_du`，抑制指令抖动）
- 子目标距离惩罚（终端，`w_subgoal`）
- 制动不等式约束（显式匀减速刹停，`a_brake`）

## 当前已知问题（2026-08-30 状态，2026-09-04 更新）

1. **全程左右/上下振荡（bang-bang 饱和）(已通过调参解决)**
   - 现象：`vx` 约 83% 时间饱和 ±2.0，`vy`/`vz` 也频繁打到 ±2；实际轨迹横向偏差以 0.6~1.2 Hz 来回换边，最大约 0.44 m，高度也有 ±0.06 m 抖动。
   - 根因：`w_subgoal=20000` 与 `w_u=20`（当前 launch 值，此前为 1）悬殊，最优解长期钉在输入盒角点；预测时域 0.5 s < τ_v≈0.7~0.8 s，控制器看不到超调；解耦后横向通道无阻尼；障碍物（`detect_range=1.0`）在狭窄走廊加剧抖动。
   - 建议修法：`w_subgoal` 降到 3000~5000、`w_u` 提到 20~50、`N` 加到 15~20、`lookahead` 提到 1.5~2.0；或中间步加小权重子目标/横向偏差惩罚。
   - 状态：调参进行中（2026-08-30 已尝试 `w_u=20`、`τ_v=0.7`，尚未确认收敛效果）。
2. **终点前频繁 "current speed exceeds braking feasibility" 警告**
   - 现象：终点前 `v·0.8 > d_g` 频繁触发 hold（录包中最高 34% 采样），形成"推—刹—推"极限环，最后以 0.02~0.05 m/s 爬行进终点。
   - 根因：精确停车约束 `τ_v·||v|| ≤ d_g`（τ_v=0.8）在低速段过严：v=0.17 m/s 需 `d_g ≥ 0.136 m`，而到达锁定条件为 `d<0.1 且 v<0.1`，二者难以同时满足。
   - 建议修法：改回显式减速度形式 `||v||² ≤ 2·a_brake·d_g`（`a_brake` 取 1.0~1.5 m/s²），或改用更小的制动等效 τ；节点制动预检需同步。
   - 状态：已实现（2026-09-04，选方案 A，`mpc/a_brake` 默认 1.2 m/s²，约束与节点
     预检同步改为 `v² ≤ 2·a_brake·d_g`），待仿真验证收敛效果。
3. **起步横向偏移（2026-08-29 分析，换模型后仍存在，但明显缓解）**
   - 起步瞬间 MPC 先斜冲（横向偏移约 0.2 m）再回到路径：短时域 + 输入盒角点饱和所致，与 yaw/速度耦合无关，需靠增大 N 或调权重解决。

## 关键文件与常用命令

- `src/mpc.cpp`、`include/form_nav/mpc.h`：MPC 核心（模型、离散化、Opti 构建与求解）。
- `src/mpc_node.cpp`：ROS 节点（状态填充、指令发布、邻居轨迹、可视化）。
- `src/astar_node.cpp`（纯 A*，默认）、`src/kino_astar_node.cpp`（kinoA*，未启用）。
- `launch/formation_test.launch`（编队测试，`global_planner:=astar/kino_astar`）、`launch/single_test.launch`（单机）、`launch/mpc.launch`（MPC 参数）。
- `config/formations.yaml`：编队偏移与邻居拓扑（DAG）。
- `bag/`：录包；`docs/`：参考论文与实验输出。
- 构建与运行：`cd ~/catkin_ws && catkin_make && source devel/setup.bash`；单机 `roslaunch form_nav single_test.launch`，编队 `roslaunch form_nav formation_test.launch`。
